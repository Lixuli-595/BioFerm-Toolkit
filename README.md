
# BioFerm-Toolkit

BioFerm-Toolkit is an open-source toolkit for data analysis and visualization in fermentation research, metabolomics, and network pharmacology.

The project aims to provide simple and reproducible Python workflows for researchers working with biological and food fermentation data.

## Development Roadmap

- Metabolomics data preprocessing
- Differential metabolite screening
- PCA analysis
- Volcano plot and heatmap visualization
- GO and KEGG enrichment visualization
- Network pharmacology data processing
- Fermentation experiment data analysis
- Scientific figure generation
